# 隐私政策

生效日期：2026-10-27

“对话导出助手”是一个 Chrome 扩展，用于帮助用户将豆包、DeepSeek 网页版中的当前对话导出为本地 Markdown 或 JSON 文件。

## 我们收集哪些数据

扩展会在豆包、DeepSeek 的对话详情页显示一个悬浮导出按钮。扩展仅在用户主动点击导出后，从当前页面读取对话内容，用于生成用户请求的本地导出文件。

扩展不会收集、保存或上传以下数据：

- 账号密码
- cookie 或登录 token
- 浏览历史
- 支付信息
- 联系人信息
- 精确位置
- 用户导出的对话文件

## 数据如何使用

读取到的对话内容仅用于生成用户选择的 Markdown 或 JSON 文件。导出文件保存在用户本地浏览器下载目录。

扩展不会将对话内容发送给开发者服务器，也不会用于广告、画像、数据转售或其他与导出功能无关的用途。

## 数据共享

扩展不会向开发者或第三方服务器传输用户对话内容。

为获取用户当前账号有权访问的对话数据，扩展会向当前页面所属的网站发起请求：

- 豆包：请求发往 `doubao.com`，使用浏览器当前登录态。
- DeepSeek：请求发往 `chat.deepseek.com`。扩展在页面内记录页面自身请求所用的请求头（包括登录 token），或读取页面本地存储中的登录 token，仅用于在页面内向 `chat.deepseek.com` 请求当前会话的历史消息。token 只在页面内使用，不会被保存、传给扩展其它部分或发送到其它网站。

这些请求由对应网站的服务处理。

## 权限使用

activeTab：
用于在用户点击扩展并发起导出时，临时访问当前活动的对话页面。

scripting：
用于在用户从弹窗发起导出时，向当前活动页面注入导出脚本。

站点访问 `https://*.doubao.com/chat/*` 和 `https://chat.deepseek.com/*`：
用于在对话详情页显示悬浮导出按钮，并在用户点击按钮后读取当前会话内容。扩展不会在用户未点击导出时生成或上传对话数据。

## 有限使用声明

本扩展对用户数据的使用遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。扩展仅将用户数据用于提供或改进“将当前对话导出为本地文件”这一单一用途，不会将用户数据用于广告、出售、转让或与该功能无关的目的。

## 数据保留

扩展不在开发者服务器保存任何用户数据。导出的文件由用户本地保存和管理。

## 联系方式

如需联系开发者，请在 Chrome Web Store 商品详情页使用开发者提供的支持邮箱或支持链接。
